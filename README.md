### Selected work

**[Lyfe Health Check-In](https://santisky8.github.io/#check-in)**: AI health agent, built solo in 3 days for the Open Agent Hackathon 2026 (GenAI Works, Track 02).
A 10-step agent pipeline on NVIDIA Nemotron. A danger filter runs before any model call, answers come from 1,016 MedlinePlus topics and live PubMed reviews, and every answer line is cited. 70 safety tests.
[Live demo](https://santisky8.github.io/lyfe-health-checkin/) · [Code](https://github.com/santisky8/lyfe-health-checkin) · [Video](https://www.youtube.com/watch?v=pd6DNtmnUbw)

[![Lyfe Health Check-In demo video](https://santisky8.github.io/img/checkin-video.webp)](https://www.youtube.com/watch?v=pd6DNtmnUbw)

**[Lyfe Health](https://santisky8.github.io/#lyfe-health)**: wellness platform, sole engineer. Website live at [lyfehealth.ca](https://lyfehealth.ca); Flutter app in development.
A multi-agent pipeline (5 LLM agents, OpenAI and Claude APIs, RAG) cut article production from 8 to 12 hours to 15 minutes. Astro, React, Supabase, Cloudflare R2, Netlify: zero hosting cost and 50% faster page loads.

**[Lyfe Time](https://santisky8.github.io/#lyfe-time)**: Android planner in Flutter, in development. Saved posts and screenshots become small steps on your calendar. [lyfetime.ca](https://lyfetime.ca)

**[byok_llm](https://github.com/santisky8/byok_llm)**: open-source Dart SDK on [pub.dev](https://pub.dev/packages/byok_llm). Typed JSON replies from 6 LLM providers with the user's own key, model fallback, retries, cancel tokens and 11 sealed error types. 27 tests, CI on 2 Dart versions.
